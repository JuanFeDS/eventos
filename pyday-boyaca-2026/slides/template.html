Combinando columnas de Streamly

  2. 2payment_risk — función de failed_payments y payment_method
  3. 3customer_activity — combinación de devices_used y unique_content_last_30d
  4. 4support_intensity = support_tickets + complaints

Nota al margen

Como cada cliente de Streamly aparece varias veces (una fila por mes), ese random_state=42 puede dejar el mes 3 de un cliente en train y su mes 4 en test. Es un problema real y da para una charla completa — hoy no es el que nos ocupa.

Guía de esta plantilla

4 moldes de marca sacados de "Diapositivas base para PyDay Boyacá.pdf" + 6 moldes de contenido para pasar el guion a slides, todo con el mismo motor de navegación del prework de Django Girls (flechas, dots, swipe, teclado).

Portada
.slide--cover

Título de la charla + nombre del ponente. Usar una sola vez, al inicio.

Título de sección
.slide--section

Divide temas — un título corto + una línea de contexto.

Declaración
.slide--statement

Una pregunta o frase corta a media pantalla, sobre el fondo olivo — para las preguntas incómodas del guion.

Callout
.slide--callout

Una sola frase a pantalla completa sobre fondo dorado — usar con moderación, para el cierre de una etapa.

Código
.slide--paper .slide--code

Bloque(s) de código sobre fondo claro. .code-grid.cols-2/3 para comparar snippets lado a lado.

Árbol de carpetas
.slide--tree

Estructura de directorios en monoespaciado sobre fondo oscuro — para los src/ de cada etapa.

Lista numerada
.slide--paper .slide--list

Lista con círculos numerados sobre fondo claro — features, pasos, checklist de "qué no sabes".

Nota al margen
.slide--paper .slide--aside

Tarjeta punteada para un comentario secundario sin interrumpir el eje principal — así se metió el leakage.

Contacto
.slide--contact

Vías de contacto del ponente — usar cerca del cierre.

Cierre
.slide--thanks

"¡Gracias!" + franja de auspiciantes (Python Colombia, PyLadies Boyacá, Django Girls Colombia).
