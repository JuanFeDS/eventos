# streamly-churn

Estructura final de proyecto usada como referencia visual en la charla
*"Más allá del notebook"* (PyDay Boyacá 2026). No es el pipeline real de la
demo (ver `../demo-streamly/`) — es el árbol de carpetas completo, con
archivos representativos, para tomar capturas de pantalla reales en vez de
ilustraciones de código.

```
streamly-churn/
├── data/
├── notebooks/
├── src/
│   ├── data/
│   ├── features/
│   ├── models/
│   ├── evaluation/
│   └── utils/
├── configs/
├── experiments/
├── tests/
├── train.py
├── predict.py
└── README.md
```
