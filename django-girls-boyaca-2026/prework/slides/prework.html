Bienvenida y expectativas

Antes de instalar nada, esto es lo que importa

¿Qué es Django Girls?

Vas a escribir tu primer código.

Django Girls es un taller pensado para quienes nunca programaron. Al final del día vas a tener un blog propio, funcionando en internet, hecho por ti.

Importante

El objetivo no es aprender a programar en un día.

Es perderle el miedo al código y pasarla bien. Si algo no instala a la primera, es normal — para eso está este prework y el canal de ayuda (tema 9).

03

Línea de comandos

Lo mínimo para movernos sin miedo

Paso a paso

Abre la terminal

No es hackear: es solo darle instrucciones a la computadora, una por una.

  1. 1

    Busca PowerShell en el menú de inicio y ábrela.

  2. 2

    Escribe cd Desktop y presiona Enter para moverte al escritorio.

  3. 3

    Escribe mkdir django-girls para crear una carpeta nueva.

Terminal

Así se ve en la práctica

Prueba estos comandos, uno por uno:

$cd Desktop
$ls
Desktop Documents Downloads Pictures

Paso a paso

Hazla tuya

Una terminal con buen color da más ganas de abrirla. Esto toma dos minutos.

  1. 1

    Instala Windows Terminal desde la Microsoft Store (en Windows 11 ya viene instalada).

  2. 2

    Ábrela y entra a Configuración → tu perfil de PowerShell.

  3. 3

    En Apariencia, elige un esquema de color — por ejemplo One Half Dark o Solarized Dark.

  4. 4

    Si la letra se ve chica, sube el tamaño de fuente ahí mismo.

Bonus opcional

¿Quieres ir más allá?

Busca Oh My Posh — le da a tu prompt iconos y hasta el estado de tu repo de git a simple vista. No es necesario para el taller, pero si te gusta personalizar, vale la pena mirarlo después.

04

Instalación de Python

Setup · lo vas a necesitar para todo lo demás

Paso a paso

Instalación de Python

  1. 1

    Entra a python.org/downloads desde tu navegador.

  2. 2

    Descarga la versión para Windows (el sitio la detecta sola).

  3. 3

    Abre el instalador y marca la casilla Add Python to PATH antes de instalar.

  4. 4

    Sigue el asistente hasta el final y ciérralo cuando termine.

Terminal

Verifica que Python quedó instalado

Abre la terminal y escribe esto:

$python --version
Python 3.12.4

Terminal

Deja esto listo desde ya

Windows bloquea por defecto los scripts de PowerShell (.ps1). Más adelante, en el taller, vas a necesitar correr uno para activar un entorno virtual de Python — mejor resolverlo ahora que a mitad del taller.

$Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Confirma con "S" si te lo pregunta

Cuenta de GitHub

Tu usuario en la comunidad de código

Paso a paso

Crea tu cuenta

  1. 1

    Entra a github.com.

  2. 2

    Haz clic en Sign up.

  3. 3

    Elige un nombre de usuario, tu email y una contraseña.

  4. 4

    Confirma tu cuenta desde el mail que te llega.

Importante

Todavía no vas a usar GitHub.

Hoy solo creamos la cuenta. Cómo usarla la vas a aprender en el taller.

07

Instalación de Git

El programa, no la cuenta — son cosas distintas

Paso a paso

Instalación de Git

  1. 1

    Entra a git-scm.com/downloads.

  2. 2

    Descarga el instalador para Windows.

  3. 3

    Instala dejando todas las opciones por defecto.

  4. 4

    Configura tu nombre y email: git config --global user.name "Tu Nombre" y después git config --global user.email "tu@email.com".

Terminal

Verifica que Git quedó instalado

Escribe esto en la terminal:

$git --version
git version 2.45.0

Paso a paso

Conecta Git con GitHub

Así el taller no se frena pidiéndote usuario y contraseña cada vez.

  1. 1

    Instala GitHub CLI desde cli.github.com.

  2. 2

    Abre la terminal y escribe gh auth login.

  3. 3

    Elige GitHub.com → HTTPS → Login with a web browser.

  4. 4

    Copia el código que te muestra, pégalo en el navegador que se abre y confirma.

Terminal

Confirma la conexión

De vuelta en la terminal, escribe:

$gh auth setup-git
$gh auth status
Logged in to github.com as tu-usuario

Importante

Ya está todo conectado.

Instalamos Git, lo configuramos y lo enlazamos con tu cuenta de GitHub. Lo único que falta es tu primer git commit — y eso lo vas a aprender paso a paso en el taller.
