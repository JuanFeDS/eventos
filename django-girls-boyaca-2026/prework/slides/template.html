Instalación de Python

  1. 1

    Entra a python.org/downloads desde tu navegador.

  2. 2

    Descarga la versión para tu sistema operativo (Windows, Mac o Linux).

  3. 3

    Abre el instalador. En Windows, marca la casilla Add Python to PATH.

  4. 4

    Sigue el asistente hasta el final y ciérralo cuando termine.
