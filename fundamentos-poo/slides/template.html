Clases y objetos

La base de todo lo demás

Concepto

Una clase es un molde. Un objeto es lo que sale de él.

Defines la clase una sola vez y luego creas tantos objetos (instancias) como necesites, cada uno con sus propios datos.

Analogía Un molde de galletas es la clase. Cada galleta horneada es un objeto — misma forma, pero cada una es su propia galleta.

Código

Definir una clase e instanciarla

Python usa class para definir el molde y llama automáticamente a __init__ al crear cada objeto.

perro.py
class Perro:
    def __init__(self, nombre):
        self.nombre = nombre

mi_perro = Perro("Firulais")
print(mi_perro.nombre)
Firulais
