### Conclusiones
- **Bug crítico de pérdida de contenido**: el archivo `prework.html` se sobrescribió con una versión vieja de 26 slides (probablemente un buffer viejo del editor guardado encima) — se recuperó exitosamente extrayendo el contenido del backup local que guarda la herramienta de Artifact al publicar
- Tres gotchas de CSS/JS reales encontrados y documentados en memoria del proyecto:
  1. `overflow-y: auto` sin `overflow-x` explícito activa `overflow-x: auto` automáticamente (regla real del spec CSS) — rompe layouts full-viewport con `flex:0 0 100vw`
  2. Cualquier archivo HTML de este repo que se sirva por GitHub Pages necesita su propio `<meta viewport>` explícito — la herramienta de Artifact lo inyecta sola, pero GitHub Pages sirve el archivo crudo tal cual
  3. `scrollIntoView` en un elemento sin scroll real busca el ancestro scrolleable más cercano y puede terminar scrolleando un contenedor mucho más grande (`overflow:hidden` no impide scroll programático) — mejor calcular `scrollLeft` a mano
  4. El motor de `translateX` del carrusel debe medir el ancho real en píxeles vía JS (`.app.clientWidth`), nunca reconstruir `Nvw` o usar porcentaje mal calculado — ambos causaron bugs de slides que se cortaban entre sí
